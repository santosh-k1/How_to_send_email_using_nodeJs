# 📧 How to Send Email Using Node.js – Nodemailer Tutorial

This project demonstrates how to send emails using Node.js with the **Nodemailer** library. It's ideal for backend developers who want to integrate email functionality into their applications — whether for contact forms, notifications, or automated workflows.

## 🚀 Features

- Send plain text and HTML emails
- Use Gmail, Outlook, or custom SMTP
- Environment variable support for secure credentials
- Error handling and logging
- Easy-to-understand code structure

## 🛠️ Technologies Used

- Node.js
- Nodemailer
- dotenv
